## 📝 NUMBERING RULES

### Format
```
NNN_YYYY-MM-DD_AGENT_ReportType_Description.md
```

**Example:**
```
001_2026-03-22_ANTIGRAVITY_Recovery_VerificationReport.md
```

### Rules
1. **Three-digit number** (001, 002, 003...)
2. **Date** (YYYY-MM-DD format)
3. **Agent name** (ANTIGRAVITY, QWEN, CODEX, etc.)
4. **Report type** (Recovery, Audit, Handoff, Strategy, etc.)
5. **Description** (camelCase or underscores)

### Assignment
- **001-099:** Current month (March 2026)
- **100-199:** Next month (April 2026) - if needed
- **Lowest number = Latest report**
