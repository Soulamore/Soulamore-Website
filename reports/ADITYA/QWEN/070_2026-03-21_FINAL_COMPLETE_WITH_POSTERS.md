## 🎯 POSTER GENERATOR FEATURES

### **What It Does:**
- **Generate Posters:** Create professional posters for any support group
- **Customizable:**
  - Group name
  - Facilitator name & credentials
  - Date & time
  - Location/platform
  - Join link (QR code)
- **Multiple Sizes:**
  - A4 (210x297mm) - For notice boards
  - A3 (297x420mm) - For walls
  - Instagram (1080x1080px) - For social media
- **Download Options:**
  - PDF (print-ready)
  - PNG (digital)
  - Print directly

### **How to Use:**
1. Visit: `http://localhost:3500/pages/poster-generator.html`
2. Fill in the form:
   - Support Group Name
   - Facilitator Name
   - Credentials
   - Date & Time
   - Location
   - Join URL
3. Select size (A4, A3, or Instagram)
4. Click "Generate Poster"
5. Download PDF/PNG or Print

- ✅ Soulamore branding
- ✅ Gradient header (teal to peach)
- ✅ Group details clearly displayed
