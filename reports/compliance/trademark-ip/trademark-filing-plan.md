## Filing Strategy and Priority

### Phase 1 — India Filing (Immediate, 0–3 months)
File all primary word marks in India first. This establishes priority date and gives you the foundation for international filing under the Madrid Protocol.

**Priority order:**
1. HASHLILLY — Class 35, 42 (corporate brand — highest priority)
2. SOULAMORE — Class 42, 44 (most differentiated, sensitive category)
3. THAT'S MISSING — Class 35, 42
4. BOOZEDIN — Class 35, 42, 43

**Remaining marks (Phase 1b — 3–6 months):**
5. DESKAI — Class 35, 42
6. RESUME ENGINE — Class 35, 42
7. LILLYPOST — Class 35, 42
8. TERRACLAW — Class 35, 42

**India filing notes:**
- Filing fee: INR 4,500 per class per mark (e-filing, small entity / startup)
- Application through IP India portal: ipindia.gov.in
- Examination period: typically 12–18 months
- Total cost estimate (8 marks × avg 2 classes): ~INR 72,000–90,000 in official fees
- Use a registered trademark agent for professional prosecution

### Phase 2 — Madrid Protocol International Filing (6–18 months after India filing)
Once India applications are filed, use the Madrid Protocol (WIPO) to designate multiple countries through a single international application, using the India application as the base.

**Priority jurisdictions:**
| Jurisdiction | Rationale |
|---|---|
| European Union (EUIPO) | GDPR compliance anchor; EU market for That's Missing, BoozeD In |
| United States (USPTO) | Largest startup / SaaS market for That's Missing; BoozeD In |
| United Kingdom (UKIPO) | Strong drinks industry; BoozeD In priority market |
| Australia (IP Australia) | English-speaking; drinks industry; wellness market |
| Singapore (IPOS) | Southeast Asia hub; tech and F&B |
| UAE (MOCCAE) | Expanding market; BoozeD In F&B industry relevance |

**Madrid filing notes:**
- Base fee: CHF 653 + CHF 100/class for basic countries; additional fees per designated country
- Requires Indian TM application or registration as base
- File through CGPDTM (Indian TM Office) as office of origin
- International registration valid 10 years, renewable

### Phase 3 — Logo / Device Marks (After final brand design lock)
File device marks (logos) in same classes as word marks, same jurisdictions.

## Pre-Filing Clearance Search

**Before filing any mark, conduct a clearance search:**

| Search Type | Tool | Purpose |
|---|---|---|
| India TM search | ipindiaonline.gov.in/tmrpublicsearch | Check existing marks in India |
| WIPO Global Brand Database | branddb.wipo.int | International conflicts |
| EU trademark search | euipo.europa.eu/eSearch | EUIPO conflicts |
| USPTO search | tmsearch.uspto.gov | US conflicts |
| Common law search | Google, web search | Unregistered marks in use |
| Domain name check | WHOIS + domainr | Domain conflicts (boozedin.com, etc.) |

**If a conflict is found:** Do not file without legal opinion. Consider: design-around, negotiate coexistence agreement, or challenge the existing mark if it's weak/unused.

## Trademark Monitoring (Post-Filing)

Once marks are filed, set up watching services:
- **India:** CGPDTM Journal monitoring (free via portal) or use agent for alerts
- **International:** WIPO ALERT service; TrademarkNow; CompuMark (paid, comprehensive)

**Monitor for:**
- New applications that are confusingly similar to your marks
- Similar marks in related classes (even if different class — risk of confusion)
- Domain registrations using your brand names
- Social media handle squatting

Respond to conflicting marks via Opposition proceedings within 4 months of publication (India).

---

## ® vs ™ Usage

- ™ (TM) — Can be used immediately once an application is filed or even before. Signals claim to the mark.
- ® (R in circle) — Can only be used after the mark is registered. Using ® before registration is a legal offence in India.

**Policy:** Use ™ on all Hashlilly products and communications once applications are filed. Switch to ® only after registration certificates are received.
