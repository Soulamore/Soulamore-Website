## What to Watch

### Level 1 — Official Registry Monitoring
- **India:** CGPDTM Trademark Journal (published weekly) — watch for new applications similar to any Hashlilly mark in Classes 35, 41, 42, 43, 44
- **EUIPO:** EUIPO eSearch (if Madrid designation filed)
- **USPTO:** USPTO TESS (if US designation filed)
- **WIPO:** WIPO ALERT service for international applications

**Similarity criteria to flag:**
- Identical marks in same or related classes
- Phonetically similar marks (e.g., "HashLily," "SoulAmore," "That's Missed")
- Visually similar marks or logos
- Marks in overlapping industry sectors even if slightly different spelling

## Response Protocol

### Scenario A — New TM Application Published (India)
**Timeline:** You have 4 months from publication date in TM Journal to file Opposition.

Steps:
1. Receive alert from watching service or agent
2. Attorney assesses likelihood of confusion within 2 weeks of alert
3. If confusion likely → file Notice of Opposition within 4-month window
4. Opposition filed at CGPDTM; hearing process follows
5. Document all correspondence and costs

### Scenario B — Registered Mark Found to Conflict
1. Attorney assesses validity and commercial use of existing mark
2. Options:
   - Negotiate coexistence agreement (if different markets)
   - File cancellation/revocation if mark is unused (non-use petition after 5 years non-use)
   - Modify own mark or product name (last resort)
3. Do not commence use of a conflicting mark without legal clearance

### Scenario C — Third Party Using Your Mark Without Registration
(Common law infringement / passing off)
1. Document: screenshots, URLs, dates, extent of use
2. Legal counsel drafts Cease and Desist letter
3. If no response within 14 days → escalate to court or mediation
4. For domain squatting: UDRP complaint (WIPO) or INDRP (India) — faster and cheaper than litigation

### Scenario D — Social Media Impersonation
1. Document account (screenshots)
2. File impersonation report via platform's IP/trademark reporting tool:
   - Instagram: Report → Intellectual Property → Trademark
   - LinkedIn: Report profile → Fake profile / using our brand
   - Twitter/X: Report → Impersonation
3. Include TM application number or registration number in report
