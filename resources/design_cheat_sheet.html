Global CSS Token Mapping

Include these theme root rules inside global stylesheets to align with Soulamore layout dimensions and geometries: 

:root {
  --font-heading: 'Outfit', sans-serif;
  --font-body: 'Plus Jakarta Sans', sans-serif;
  
  --radius-main: 32px; /* Smooth card curvature */
  --radius-sm: 24px;   /* Minor control items */
  --blur-main: 12px;   /* Standard glass backdrop blur */
  --header-clearance: 110px;
}
