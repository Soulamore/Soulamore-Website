# Operational Directives & Rules
- **Direct & Crisp:** Avoid conversational fillers or introductory fluff. Get straight to the technical core.
- **Visual Superiority:** Every interface must feel extremely premium, responsive, and wowed at first glance.
- **Absolute Modularity:** Keep modules focused, cleanly structured, and cleanly separated.
- **Robust Security:** Always validate inputs, enforce Firebase Security Rules, and audit dependency risk.
